修复 ChessPilot 0.6.2 在 Hook 已连接时仍显示「等待对局」、当前 FEN 为空的问题。

- 初始化新对局时，保留多邻国刚建立的棋盘，连同走棋方、历史和新对局标识一起上报。
- 即时棋盘暂时读不到时，使用同一开局初始化生成的棋盘状态，或多邻国提供的起始 FEN 和走棋历史。
- 对局结束时继续取消待执行的自动走棋和搜索。同一局的棋盘同步和桥接重连保留结算状态，确认新开局后恢复。

此包适配多邻国 6.105.2（2497）、ARM64 和 libxposed API 102。沿用上一版签名，可覆盖安装 0.6.2。安装后重新打开多邻国并启动 ChessPilot 引擎服务。[GitHub Actions 构建](https://github.com/chorusfruit-233/ChessPilot/actions/runs/44159387693)

回归用旧版复现了开局 FEN 被清空，并用真实的本机 TCP 桥接验证新版能接收开局并开始分析。保留结算状态、下一盘恢复和极限思考的回归测试也通过。Android 真机上的 Hook 与触摸联动待验证。
