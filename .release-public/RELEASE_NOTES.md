### 人机对局结束

棋盘确认将死时立即停止自动走棋，取消排队的点按、分析和极限思考。每次点按前都会重新核对实际棋盘。

### 极限思考设置

在「功能设置」开启「极限思考」后，可以设置独立的固定深度（0～40 层）和思考时间（100～10000ms）。深度为 0 时按时间搜索。预搜索达到预算后保留已算好的应招，预测命中时直接复用。

两项设置适用于本地和远程预计算。使用电脑算力时，源码包里的 `pc/pc_engine.py` 支持在电脑端执行预算。旧脚本可以继续连接，由手机结束预搜索。

ARM64 合包沿用上一版签名，可覆盖安装。已核对多邻国 6.105.2（2497）和 6.106.3（2501）的原生接口，Android 真机对局待验证。 [GitHub Actions 构建](https://github.com/chorusfruit-233/ChessPilot/actions/runs/45063514912)
