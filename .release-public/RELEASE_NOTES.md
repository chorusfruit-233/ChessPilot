ChessPilot 0.6.2 在多邻国结算时立即停止自动走棋。支持多邻国 6.105.2（2497）、ARM64 和 libxposed API 102，沿用单 APK 安装方式。

- 读取人机、PvP 和迷你棋赛的结算事件，识别将死、和棋、超时、认输等结果。控制页和悬浮窗显示已知的结算原因。
- 结算或离开棋盘时，取消尚未执行的选子、落点和重试，停止主搜索与预计算，并拒绝迟到的走棋指令。棋面没变化或桥接重连时，已结束的对局仍保持停止。
- 确认新开局后恢复自动走棋，即使新旧两局从同一个局面开始。

使用电脑远程引擎时，同时更新本版本源码中的 `pc/pc_engine.py` 并重启电脑端服务，让手机因结算断开时，电脑也停止对应搜索。

安装包由 GitHub Actions 构建，沿用上版测试签名，可覆盖安装 0.6.1。升级后重启 ChessPilot 引擎服务。如框架尚未加载新模块，结束多邻国进程后重新打开。[构建记录](https://github.com/chorusfruit-233/ChessPilot/actions/runs/44155209123)

云端通过 35 项 Kotlin、9 项映射和 6 项真实 Stockfish 测试。回归覆盖结算时 FEN 不变、迟到结果、同 FEN 新开局、重连和远程搜索取消。Hook 映射已对照多邻国 6.105.2 的 APK 核验。触摸落子和结算界面联动仍待 Android 真机确认。
