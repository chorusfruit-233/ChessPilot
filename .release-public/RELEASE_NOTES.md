- FEN 先到、走棋历史后补齐时，完整历史会重新上报。
- 以 FEN 的走子方为准，避免滞后的回合字段误取消预计算。
- 引擎目标 FEN 完全匹配时，可识别尚未补上对手一步的旧历史；矛盾历史和不同目标局面仍拒绝复用。

- 自动走棋指令记录 `source=ponder/search`；预测命中直接采用预备应招，真正未命中时正常搜索。
